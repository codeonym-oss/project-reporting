# Security policy

The latest minor release (`0.x`) gets fixes. Report a vulnerability privately:
https://github.com/codeonym-oss/project-reporting/security/advisories/new. Please don't open a public issue.

In scope: a skill that writes to a tracker, a forge or a published page without asking; internal findings (Gaps)
reaching a report; unsafe handling of a branch, file or key name in `scripts/`.
